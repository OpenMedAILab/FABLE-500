## Package Scope

This public package contains de-identified fundus and B-scan images, public
metadata, documentation, and per-file checksums. Raw B-scan PDF reports and
additional clinical records are not part of the public package. The default
metadata is English; original Chinese clinical text is provided separately as
an optional companion file.
